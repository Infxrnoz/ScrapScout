Integrations

Everyone adds their own keys. Both are free and stay on your PC.
Steam Web API key: lists every server in Browse, and fills in hours, friends and bans on Threats cards. Get one at steamcommunity.com/dev/apikey (any domain name works, e.g. localhost).
RustMaps API key: adds resource heatmaps to the map. Sign in at rustmaps.com → Dashboard → API.

In-game overlay

Shows over Rust in Borderless/Windowed mode. Click-through: it never takes your mouse or keyboard. In game: Ctrl + Alt + M opens the whole app over the game, Ctrl + Alt + O toggles the HUD, Ctrl + Alt + X the crosshair. Some community servers don't allow crosshair overlays, so check the rules.

Alerts

Raid alarm escalation

When a smart alarm goes off, keep ringing until someone answers: a siren in RustScout and a Discord ping, repeated until a teammate types !ack in team chat or Discord, or clicks I'm on it.

Phone view

See the map, your team, pop and alerts on your phone while RustScout runs on this PC. Your phone must be on the same Wi-Fi. View only: nothing on the phone can change switches or settings.

Scan it with your phone camera. If Windows asks whether RustScout may use the network, allow Private networks. Anyone with this link on your Wi-Fi can view it, so don't share it.

Stream overlay (OBS)

Show your server, team and alerts on stream. In OBS: Sources → + → Browser, paste the link, set width 400 and height 600. The background is see-through.

Streaming your team's positions invites stream snipers, so the overlay never shows the map.

Removed by Facepunch

On 6 August 2026 Facepunch removed shops (vending machines) and map events (patrol heli, cargo ship, Chinook, locked crates, explosions, travelling vendor, oil rigs and airdrops) from Rust+. No companion app can see them anymore, so RustScout no longer has the Shops tab, sulfur sale tracking, raid targets, event timers, event alerts, or the chat commands for them (!events !cargo !heli !chinook !vendor !crate !oil !small !large !airdrop !shop !sulfur). If Facepunch brings that data back, those features will come back too.
